# WordPress Hooks Lab

A running, daily log of WordPress hooks, filters, and small snippets —
documented as I work through them. Each file covers one hook or one
useful snippet: what it does, when it fires, a working example, and
any gotchas worth knowing.

## Structure
- `actions/` — WordPress action hooks
- `filters/` — WordPress filter hooks
- `notes.md` — misc snippets and quick references

Updated regularly.
